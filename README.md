# 🛒 DummyJSON Store - React Project

Aplicação e-commerce construída em React 19, Mantine UI e TypeScript, integrada à API DummyJSON. Conta com autenticação, catálogo de produtos, painel administrativo (CRUD local resiliente), validação de formulários com Zod e cobertura de testes unitários e E2E.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Mantine UI, Tabler Icons
- **Roteamento & Estado:** React Router DOM v7, Context API
- **Formulários & Validação:** Mantine Form + Zod
- **API & Requisições:** Axios + DummyJSON API
- **Testes Unitários:** Vitest + React Testing Library + JSDOM
- **Testes E2E:** Playwright
- **CI/CD & Hosting:** GitHub Actions + GitHub Pages

## 🚀 Como Executar Localmente

```bash
# 1. Instalar as dependências
npm install

# 2. Executar em modo de desenvolvimento
npm run dev
```
